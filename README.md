# Deal Desk Command Center

A single-page deal desk tracker. Data is stored only in the browser on the device you use. Nothing is sent to a server.

## Put it on GitHub Pages
1. Create a **private** repository and upload these four files: `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`.
2. Settings → Pages → Deploy from branch → `main` / root. (Private-repo Pages needs a paid GitHub plan; otherwise open `index.html` locally.)
3. Open the Pages URL. In Chrome or Edge, use **Install app** in the address bar to put it on your desktop or phone. It works offline.

## Keep your data safe
- Use account aliases or opportunity IDs, not customer names. Keep pricing files and contract text in Adobe systems.
- Matrix & data → **Copy backup** regularly and store it somewhere approved.
- Clearing browser data erases deals. Restore from a backup if that happens.

## First run
1. Matrix & data: set approver names, backups, SLAs, lane rules and your quarter-end date.
2. Clear the sample deals, then add real deals with **New deal** (press N) or **Import CSV** from a Salesforce report.
